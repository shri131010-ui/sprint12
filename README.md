# 🎬 Cine-Stream — Sprint 12
https://sprint12-48wc.vercel.app/

Cine-Stream is a Netflix-inspired movie explorer built with **Next.js, React, Redux Toolkit, and TMDB API**.

## 🚀 Sprint 12

This sprint focuses on **Storybook integration** for isolated UI component development and documentation.

### ✨ Features

* 🎥 Movie browsing
* 🔎 Movie search
* ⭐ Rating filter
* ❤️ Favorites
* 🌙 Dark/Light theme
* 🧪 Jest & React Testing Library
* 📚 Storybook component development

### 🛠️ Tech Stack

* Next.js
* React
* Redux Toolkit
* TMDB API
* Jest
* React Testing Library
* Storybook

### ▶️ Run Project

```bash
npm install
npm run dev
```

### 📚 Run Storybook

```bash
npm run storybook
```

Storybook runs on:

```text
http://localhost:6006
```
